## 📌 Key Performance Indicators

- **Total Recorded Net Sales:** ₹72,97,477.80
- **Total Recorded Gross Profit:** ₹23,56,599.00
- **Overall Profit Margin:** 32.29%
- **Delivery Rate:** 72.76%

## 🔍 Key Business Insights

- Recorded net sales increased by approximately 7.04% from 2024 to 2025.
- Electronics contributed approximately 38.9% of recorded net sales.
- Monitor generated the highest gross profit among the products.
- The recorded return rate was 17.52%, which warrants further investigation.

## 📝 Dataset Note

This project uses a practice dataset. Sales and profit figures include orders with different statuses, so they should be interpreted as recorded metrics rather than confirmed realized revenue.
